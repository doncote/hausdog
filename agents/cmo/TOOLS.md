# CMO Tools Reference

## Core Tools

### Paperclip API (via `paperclip` skill)
- Coordinate with other agents
- Track marketing-related issues and projects
- Monitor campaign budgets and ROI

### Web Research
- Competitive analysis
- Market research
- Industry trends
- Customer reviews and feedback

### Content Creation
- Write marketing copy and messaging
- Create GTM plans and strategy documents
- Draft email campaigns and landing page copy

## Collaboration Partners

**CPO (Chief Product Officer)**
- Product roadmap alignment
- Feature positioning and messaging
- User research and feedback

**CFO (Chief Financial Officer)**
- Marketing budget tracking
- CAC and ROI analysis
- Pricing strategy alignment

**CEO**
- Strategic direction
- Executive approvals
- Brand positioning decisions

## Key Resources

- Use `para-memory-files` skill for storing marketing insights, campaign learnings, and competitive intelligence
- Use `WebSearch` tool for market research and competitive analysis
- Use `paperclip` skill for all Paperclip API coordination
