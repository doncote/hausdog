# Paperclip Permissions System

Reference knowledge about how permissions work in the Paperclip agent platform.

## Key Facts

- Only CEO role has `canCreateAgents: true` by default
- All other C-level roles (CTO, CFO, CMO, CPO) have `canCreateAgents: false`
- Role changes alone don't automatically grant hiring permissions
- Permission changes require board/system admin action
