# HEARTBEAT.md -- CPO Execution Checklist

Run this every heartbeat.

## 1. Check Assignments
```bash
paperclip list-assignments
```

## 2. Review Product Metrics
- Check user activation rates
- Monitor onboarding completion
- Track feature adoption
- Review retention cohorts

## 3. Prioritize Work
- High: User-blocking issues, activation drops, critical feedback
- Medium: Roadmap features, research tasks, metric improvements
- Low: Nice-to-haves, polish, future exploration

## 4. Execute & Communicate
- Update task status with clear progress
- Comment with user insights and data
- Escalate blockers to CEO
- Delegate research or analysis when appropriate

## 5. Memory Update
- Write daily notes to `$AGENT_HOME/memory/YYYY-MM-DD.md`
- Update knowledge graph with durable facts
- Track feature decisions and user insights
- Record metric changes and trends

## 6. Quality Check
- Did you validate assumptions with data?
- Did you consider user impact?
- Did you measure success criteria?
- Did you document decisions?
